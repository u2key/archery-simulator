# archery-simulator

リカーブ射場シミュレータ (Archery Simulator)

`spec.md` を元にした、ブラウザで動くリカーブボウのシミュレータです。物理計算 (`src/physics/`) は DOM に依存しない ES モジュールなので、Node のテストとブラウザの両方から同じコードを使います。

## 起動

ビルドは不要です。静的ファイルとして配信して開きます (ES モジュールは `file://` では読み込めません)。

```sh
npm run serve        # python3 -m http.server 8000
# → http://localhost:8000/
```

Three.js・Vue・Tailwind は CDN (jsdelivr / cdn.tailwindcss.com) から読み込むので、ネットワーク接続が必要です。

## テスト

```sh
npm test             # node --test (Node 18 以上)
```

## 操作

| 操作 | 内容 |
| --- | --- |
| Space / 「引く」 | 引き込み → エイム。クリッカーが切れたら Space でリリースする。クリッカー前に離すと引き不足になり、保持が長すぎると戻って初速が落ちる |
| 1エンド自動 | 6本を自動で射つ (クリッカーが切れた直後にリリース) |
| 残りを一括計算 | アニメーションなしで 72 本目まで計算する |
| 1人称 / 3人称 / 矢を追う | 視点の切り替え。1人称では照準の揺れ (手ブレ＋心拍) がそのまま見え、リリース時の揺れが着弾に反映される |
| 再生 / しなり誇張 | スロー再生と、アーチャーズ・パラドックスのしなりの誇張表示 |
| 設定パネル | ボウ / スタビライザー / 矢 / 射手・環境 / サイト調整。慣性テンソル・FOC・スパイン適合などの派生値もここに表示する |

## 構成

```
index.html              画面レイアウト (Vue のテンプレート)
src/ui/app.js           状態管理・射撃の流れ・スコアシート
src/ui/scene.js         Three.js の射場・ボウ・矢・風パーティクル
src/ui/targetFace.js    WA 標的と PIP の描画
src/physics/
  config.js             既定セットアップと材質・ベインの係数表
  bow.js                3.1 引き尺 / 4.1 初速 / 4.2 慣性テンソル・リリース後の回転 (RK4 + クォータニオン)
  arrow.js              3.4 質量分布・FOC・EI・空力係数 / 4.3 パラドックス
  ballistics.js         4.4 弾道 (RK4: 位置・速度・矢の軸・首振り・自転)
  wind.js, simplex.js   4.5 べき乗則の風 + 4D Simplex 乱流
  sight.js              5 サイト調整
  scoring.js            6 WA 採点・スコアシート
  shot.js               1本の射撃 (照準 → クリッカー → 反動 → 飛翔 → 採点)
tests/physics.test.js   解析解・保存則・符号・統計的な挙動のテスト
```

## spec からの変更点と前提

- **剛体物理エンジン (Rapier / Cannon) は使っていません。** 必要な剛体計算は spec 4.2 の式 `I dω/dt + ω×(Iω) = τ − c ω` だけで、的との当たりは平面との交差判定で済みます。そこでこの式を RK4 とクォータニオンで直接積分しています。角運動量とエネルギーの保存はテストで確認しています。
- **揚力の符号 (4.4):** spec の `(d̂×v̂)×v̂` は機首と逆向きになるため、`v̂×(d̂×v̂)` (機首が向いている側) にしています。
- **マグヌス力の次元 (4.4):** spec の式は長さの次元が1つ足りないので、シャフト半径 r を掛けています。
- **4.1 初速:** spec の式 `E = ½·F·(L−BH)` をそのまま使っています。これはリムを線形バネとみなした値で、実際のリカーブより蓄積エネルギーを少なめに見積もります。そのため既定値では 38 lbs・330 grain で約 47 m/s となり、実機 (55 m/s 前後) より遅めです。合わせたい場合は η か m_eff を調整してください。
- **4.5 の高さ:** spec の式では高さを z と書いていますが、本実装の座標系は x=右・y=上・z=射線方向なので、高さは y です。
- 射手は右利きを前提としています (スパインが柔らかいと右、硬いと左へ逸れる)。
- 経験的に決めた係数 (照準の揺れ、手のトルクのばらつき、スパイン不一致による偏差、必要スパインの目安式など) は、各ファイルの先頭に定数としてまとめてあります。既定の中級者 (安定度 1.0) が無風の 18m で 1本平均 約 9 点、70m で約 8.5 点になるよう合わせています。
